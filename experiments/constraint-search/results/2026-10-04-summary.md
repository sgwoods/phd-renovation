# First benchmark contract results

Recorded for the 2026-10-04 implementation task. This is a correctness smoke run,
not a performance study. [Raw JSONL](2026-10-04-smoke.jsonl) contains all 20 records,
input/source hashes and runtime details. Source baseline: `2bdf7a8`; the harness
was new, uncommitted working-tree code whose hashes are recorded per run.

## Observations

All five materialized instances completed under all four configurations with
**exact solution-set parity** against the independent Cartesian-product oracle.
No worker errors or diagnostics occurred. Empty output was not confused with
UNSAT, and ambiguous cases retained both valid mappings.

| Fixture | Outcome / solutions | BT nodes / pair checks | FC nodes / pair checks |
|---|---|---|---|
| ordered | SAT / 1 | 6 / 4 | 3 / 5 |
| ambiguous | SAT / 2 | 6 / 4 | 4 / 6 |
| hall-sat | SAT / 2 | 12 / 14 | 6 / 20 |
| hall-unsat | UNSAT / 0 | 10 / 10 | 4 / 12 |
| unary | SAT / 1 | 1 / 0 | 1 / 0 |

FC+DR and FC+DR+advance-sort matched FC's counts on these particular tiny fixtures.
That is not evidence of equivalence in general. FC reduced nodes on four cases,
but did more pair checking. The pair-check counter measures calls to the adapter's
compiled relations, not historical ADT constraint-check counts. No timing speedup
claim is warranted; startup and verification dominate such small experiments.

The `allDifferent` constraint is pairwise-decomposed in this adapter. These Hall
fixtures are ready for a future global-filtering comparison; no Regin propagator
has been implemented here.

## Verification

- The new FiveAM suite passed **1,306 checks**, including complete-solution parity
  on 100 stable generated instances under four strategies, all five explicit
  fixtures, invalid-witness/translation mutations, unsupported n-ary adapter input,
  duplicate results, empty models/domains, state isolation and budget semantics.
- The subprocess contract checks exercise JSON records, SHA-256 input identity,
  wall timeout, zero CPU budget, first-witness incompleteness, missing files,
  forbidden reader evaluation, trailing input and an empty-model file round trip.
- Existing core suites passed **90 checks** and bounded AO suites passed **60**.
  No historical solver source, defaults, snapshots, or metric goldens changed.
- Artifact, ff provenance, ADT archive, CSP archive and dashboard validators passed.
  Artifact checking used the tracked-data fallback, not fresh historical batch runs.

Reproduce with the commands in [the benchmark README](../README.md). The research
suite is now an independent CI step, leaving the four-suite historical runner intact.

## Remaining scope

W0/W1 are not complete for the thesis domains. Historical ADT/MPR/Memory-CSP exports,
context-sensitive callbacks, real-source extraction, richer resource accounting and
large-instance certification remain open. The next algorithm comparisons are
failure-weighted ordering and CP-SAT after faithful domain exports. There were no
modern-solver, neural-model, paid-API or training runs in this work.
