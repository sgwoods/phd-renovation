# Raw Landing Zone

This directory is the easiest place to drop newly found material when you do
not want to organize it first.

Recommended path:

`/Users/stevenwoods/phd-renovation/incoming/_landing/`

## Intended Use

Use this directory when:

- you have a new batch of code, data, papers, notes, or archives,
- you want to get the material into the repo quickly,
- and you want Codex to do the naming, intake setup, and promotion work.

## What To Do

1. Copy or move the raw material into this directory.
2. Tell Codex what you dropped there and, if known, where it came from.
3. Codex will:
   - create a proper intake batch under `incoming/<date-or-source>/`,
   - register it in `incoming/INDEX.md`,
   - move the files out of `_landing/`,
   - and start the review/classification pass.

## Rule

Do not treat `_landing/` as a permanent home.
It is only a raw handoff area before the material is converted into a proper
tracked intake batch.
