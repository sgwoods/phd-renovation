# CSP Miscellaneous Artifacts

Non-core development artifacts from the original MOTORS CSP solver directory.
Moved from various subdirectories and loose files in `csp/`.

## Directories

| Directory | Files | Description |
|-----------|------:|-------------|
| RealSource/ | 40 | C source code for test programs |
| RealSource/tet/ | 26 | Tetrahedral cell simulation (C) -- used as a real-world CSP test case |
| RealSource/yacc/ | 14 | YACC parser for C grammar analysis -- extracts program structure for ADT matching |
| Devel/ | 9 | Development experiments (AC4 algorithm, extensions) |
| Interest/ | 3 | Research notes and interesting results |
| Doc/ | 2 | PostScript user documentation (UserIntro.ch1.ps, ch3.ps) |
| later/ | 1 | Deferred MPR code |

## Loose Files

| File | Description |
|------|-------------|
