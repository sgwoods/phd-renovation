# PhD Thesis

Woods, Steven G. **"A Method of Program Understanding using Constraint
Satisfaction."** University of Waterloo, Technical Report CS-96-33, 1996.

## File

- `Woods PHD CS-96-33 A Method of Program Understanding using Constraint Satisfaction.pdf` (1.5 MB)

## Abstract

Describes a constraint satisfaction approach to automated program
understanding, using Abstract Data Type (ADT) recognition as the primary
application domain. Introduces the memory-CSP two-phase search methodology
and evaluates it against direct CSP and GSAT-based approaches across
varying noise levels.
